EasyRMS architecture

How a return request travels from the customer portal or the agent back office through the Next.js API routes and domain services into PostgreSQL.

Request paths

Pages read through Server Components, which resolve services from the container. Mutations and client-side reads go through apiCall to an API route. There are no Server Actions.

Dependency direction

app → ui, core, db and db → core (types only). ui and core import nothing internal. npm run lint enforces this.

Deployment

docker-compose.yml runs three containers on one network: the webapp image, postgres:18.7 and clamav, with volumes for the database and virus signatures.
